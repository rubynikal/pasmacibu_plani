Repozitorija esošais kods ir rīks, kas ar mākslīgā intelekta palīdzību veido pašmācību plānus, ņēmot vērā lietotāja ievadītu informāciju: tematu, temata detaļas, pieejamo laiku un zināšanu līmeni. Rīks spēj arī saglabāt plānus un ļauj atzīmēt progresu.
Rīks izmanto Google izveidoto Gemini AI API, kura atslēgu ir jāievieto failā app.py. Sīkāka informācija par to ir pieejama https://ai.google.dev/
Projektā izmantoti: Python Flask, HTML, CSS, JavaScript un SQLite3.

Projekts izveidots ZPD ietvaros 2025. gadā.
